# heybox

小黑盒自动化脚本集合，基于 Node.js 实现，支持小黑盒每日任务（签到/分享/自动发帖与删帖）、盒币/等级/盒电资产查询、普通领券、定时抢券、0 元抽奖盒券等功能。

> 仅供学习交流使用。请自行承担使用风险，并遵守小黑盒平台规则。Cookie 属于敏感信息，请勿泄露给他人或提交到公开仓库。

## 功能概览

| 脚本                | 功能                                                                   | npm script             |
| ----------------- | -------------------------------------------------------------------- | ---------------------- |
| `heybox_sign.js`  | 每日签到、分享帖子/游戏/评价任务、社区自动发帖与秒删、盒币/等级/盒电输出                            | `npm run heybox_sign`  |
| `heybox_claim.js` | 普通游戏优惠券自动领取                                                          | `npm run heybox_claim` |
| `heybox_rush.js`  | 限时券/抢券任务，支持自动发现目标、定时窗口、多轮并发请求                                        | `npm run heybox_rush`  |
| `heybox_roll.js`  | 0 元抽奖盒券任务，支持活动发现、前置任务处理、参与抽奖、分享任务                                    | `npm run heybox_roll`  |

## 已支持任务

### 每日任务与资产查询：`heybox_sign.js`

支持自动完成：

| 任务 | 处理方式 |
| --- | --- |
| 每日签到 | 请求签到接口，回查签到状态，输出连签天数、H币、经验及盒电奖励 |
| 分享任意帖子到社交平台 | 双重上报（原生 App 加密事件 + 任务签名服务器），自动确认完成 |
| 分享游戏详情到社交平台 | 双重上报游戏详情分享行为，自动确认完成 |
| 分享游戏评价到社交平台 | 双重上报游戏评价分享行为，自动确认完成 |
| 社区发布内容/发帖任务 | 自动解析话题标签发布动态，待结算完成后**自动秒删帖子**，无感完成 |
| 个人资产查询与展示 | 实时提取并展示**当前盒币（折算 RMB）**、**当前等级**、**当前盒电** |

特色与安全设计：

- **凭证失效检测**：自动检测 `relogin` 状态，当 Cookie 失效时提示重新登录指引，避免无效循环。
- **自动解析标识**：从 `pkey` 自动解析 `heybox_id`，并使用 MD5 算法生成设备 `imei`。
- **动态签名算法**：通过动态 `hkey` 服务自动适配小黑盒 App 接口最新算法。
- **多轮确认重试**：任务上报后支持多轮轮询校验，确保任务状态 100% 确认完成。

### 普通领券：`heybox_claim.js`

- 拉取普通游戏券列表，自动筛选可领取、未受限优惠券。
- 自动刷新领取所需 Session，逐个完成领取。
- 登录态失效时智能暂停当前账号任务。

---

### 定时抢券：`heybox_rush.js`

- 自动发现限时/特殊优惠券目标，支持从标签解析开抢时间。
- 抢券前预热 Session，开抢窗口内多轮并发请求（支持自定义并发数与轮数）。

---

### 0 元抽奖盒券：`heybox_roll.js`

- 自动发现最新 0 元抽奖活动，拉取活动详情与盒券任务。
- 支持自动参与抽奖、自动完成 `share_act` 分享活动任务，输出任务及盒券统计。

## GitHub Actions 每日自动化托管配置教程

本项目内置了 GitHub Actions 自动化工作流（[.github/workflows/heybox_daily.yml](file:///.github/workflows/heybox_daily.yml)），无需自备服务器，即可实现每日定时自动运行。

### ⏰ 自动化定时说明
部署完成后，云端将在以下时间点**每天自动运行两次**（包含 `heybox_sign.js` 签到分享/发帖、`heybox_claim.js` 普通领券、`heybox_roll.js` 抽奖盒券）：
1. **北京时间 00:05**（凌晨 0 点过 5 分）
2. **北京时间 08:00**（早上 8 点整）

---

### 🚀 详细配置步骤（手把手教程）

#### 第一步：Fork 本仓库
1. 打开本项目 GitHub 页面。
2. 点击页面右上角的 **Fork** 按钮，将本项目复制代码库到您自己的 GitHub 账号下。

#### 第二步：添加 Secret 变量（`HEYBOX_CK`）
1. 打开您自己 Fork 后的仓库页面。
2. 点击顶部菜单栏的 **Settings**（设置）。
3. 在左侧边栏找到并展开 **Secrets and variables** $\rightarrow$ 点击 **Actions**。
4. 点击右侧绿色的 **New repository secret** 按钮。
5. 填入环境变量信息：
   - **Name**: `HEYBOX_CK`
   - **Secret**: 粘贴您从手机抓包获取的凭证，例如：
     ```text
     pkey=xxxxxx;x_xhh_tokenid=xxxxxx;
     ```
6. 点击 **Add secret** 完成保存。

#### 第三步：启用 GitHub Actions 工作流
1. 点击仓库顶部菜单栏的 **Actions** 选项卡。
2. 如果页面显示 *"Workflows are disabled on this forked repository"*，请点击绿色的 **I understand my workflows, go ahead and enable them** 按钮激活工作流。
3. 在左侧工作流列表中，您会看到 **HeyBox 每日签到**。

#### 第四步：手动触发测试（验证是否成功）
1. 点击左侧的 **HeyBox 每日签到**。
2. 点击右侧的 **Run workflow** 下拉菜单 $\rightarrow$ 再点击绿色的 **Run workflow** 按钮。
3. 刷新页面，点击正在运行的记录，点进 **heybox-daily** 可查看实时日志。
4. 若日志中成功打印出昵称、签到成功、任务完成以及盒币/等级/盒电余额，说明自动化已配置成功！此后云端会每天按时自动运行。

## 环境变量

所有脚本共用环境变量：

```bash
heybox_ck
```

包含字段：

```bash
pkey=xxx;x_xhh_tokenid=xxx;
```

### 单账号与多账号格式

- **单账号**：
  ```bash
  export heybox_ck='pkey=xxx;x_xhh_tokenid=xxx;'
  ```

- **多账号（支持换行或 `&` 分隔）**：
  ```text
  pkey=账号1;x_xhh_tokenid=账号1;
  pkey=账号2;x_xhh_tokenid=账号2;
  ```

## iPhone (iOS) Stream 抓包获取 App Cookie 教程

小黑盒 App 端 Cookie 具有非常长的有效期（**只要不在 App 内手动点击“退出登录”，可持续使用数月**）。

1. **安装 Stream**：在 App Store 下载免费抓包工具 **Stream**。
2. **安装并信任证书**：
   - 打开 Stream 点击“开始抓包”，允许添加 VPN 配置。
   - 点击“安装 CA 证书”下载描述文件。
   - 打开 iPhone **【设置】** $\rightarrow$ **【已下载描述文件】** $\rightarrow$ 点击安装。
   - 打开 iPhone **【设置】** $\rightarrow$ **【通用】** $\rightarrow$ **【关于本机】** $\rightarrow$ 最底部 **【证书信任设置】** $\rightarrow$ 勾选信任 Stream 证书。
3. **抓取 Cookie**：
   - 返回 Stream 点击 **“开始抓包”**，打开 **小黑盒 App** 刷新首页或点进任意帖子。
   - 返回 Stream 点击 **“停止抓包”**，进入 **“抓包历史”** 找到 `api.xiaoheihe.cn` 的请求。
   - 查看 **Request Headers** 中的 `Cookie`，复制出 `pkey=...;` 和 `x_xhh_tokenid=...;`。
4. **⚠️ 注意**：抓完包后直接关闭 Stream 即可，**请勿在小黑盒 App 内点击“退出登录”**。

## 本地运行

安装依赖：

```bash
npm install
```

运行脚本：

```bash
# 每日任务 (签到、分享、自动发帖删帖、资产查询)
npm run heybox_sign

# 普通领券
npm run heybox_claim

# 抽奖盒券
npm run heybox_roll

# 定时抢券
npm run heybox_rush
```
